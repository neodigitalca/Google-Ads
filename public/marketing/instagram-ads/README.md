## Meta Ads Manager setup

1. **Placement:** Instagram Feed (single image)
2. **Aspect ratio:** Upload as-is (3:4) or crop to 4:5 in Canva
3. **Primary text:** Use caption above (first 125 chars show before "more")
4. **Headline:** Use on-image headline or shorten for link preview
5. **CTA button:** Learn More (product ads) or Contact Us (Ad 2 demo)

## Polish pass (optional)

If AI-rendered text has typos, overlay final copy in Figma/Canva using **Lato** font and brand hex codes (`#02050A`, `#84BC00`, `#ffffff`, `#22d3ee`).
